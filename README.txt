StayMate Student Dashboard

Files: index.html, style.css, script.js.

LOGO:
The StayMate logo is stored as "staymatelogo.png" in this project folder and is used in the header and navigation drawer.
Keep the image alongside index.html so its relative path continues to work in Live Server.

RUN:
Extract the ZIP, open the folder in VS Code, then open index.html in a browser or use Live Server.

This is a frontend demo. Authentication, database saving, live complaint status, and logout require backend integration. Camera and gallery attachments are optional and depend on browser/device support.
